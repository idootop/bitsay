## Introduction

BitSay is a lightweight home‑screen widget for notes and todos.

View, create and edit notes & todo lists without opening the app.

Record sudden ideas, jot quick memos and track daily tasks at a glance.

## Requirements

**Android 12 (API 31) or newer.** 

The app requests **no permissions at all** — no network, no storage, no notifications.
